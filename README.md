# 🚀 Codeforces Analyzer

A full-stack Codeforces analytics platform built with **React** and **FastAPI** that provides performance insights, personalized problem recommendations, virtual contests, and user comparisons.

## 🌐 Live Demo

**Frontend:** https://your-vercel-link.vercel.app
**Backend API**: https://codeforces-analyzer-2.onrender.com/

## ✨ Features

* 📊 Analytics Dashboard
* 🔥 Activity Heatmap
* 📈 Rating Prediction
* 🎯 Smart Problem Recommender
* ⏱️ Virtual Contest Generator
* 🥊 Rival Comparison
* 🏆 Weekly Leaderboard
* ✍️ Editorials & Blogs
* 🌙 Dark/Light Mode

## 🛠 Tech Stack

* **Frontend:** React, Vite, Axios, Tailwind CSS, Recharts
* **Backend:** FastAPI, Python

## 🚀 Run Locally

```bash
# Frontend
npm install
npm run dev

# Backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
